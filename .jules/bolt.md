## 2025-05-18 - Deduplicate Class Sections in Teacher Total Students Calculation
**Learning:** `Teacher::getTotalAssignedStudentsAttribute` was summing student counts across all assignment records without deduplicating class sections. When a teacher is assigned multiple subjects in the same class section (e.g., Math and Science in Class 1-A), student counts were overcounted by 2x or 3x, and redundant property/relation evaluations were performed for each duplicate assignment.
**Action:** Deduplicate assigned class sections by unique `id` (`pluck('classSection')->filter()->unique('id')`) before computing student totals. Also ensure subject attribute fallbacks check `display_name`, `name_en`, and `name_ar` to prevent null returns when `name` column doesn't exist on `Subject`.
