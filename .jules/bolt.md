## 2026-05-13 - Deduplication and Memory Optimization in Teacher Accessors
**Learning:** In `Teacher::getTotalAssignedStudentsAttribute`, teachers assigned to multiple subjects in the same class section had their student counts multiplied per subject assignment. Furthermore, fallback count calculation accessed `$cs->students->count()`, hydrating every student Eloquent model into PHP memory instead of checking `$cs->relationLoaded('students')` or running `$cs->students()->count()`. Additionally, `assigned_subjects` checked `$subject->name` directly which returns `null` because `Subject` uses `display_name`, `name_en`, and `name_ar`.
**Action:** When calculating aggregated totals from many-to-many pivot tables, always deduplicate unique entities before reducing sums, check for relation loading state before accessing property collections, and verify model attribute names.
