## 2025-05-18 - Dashboard Analytics N+1 and View Composer Query Optimization
**Learning:** In `DashboardAnalyticsService::buildOverview`, calculating section average attendance in a loop resulted in an O(N) database query bottleneck. Eager-loading section attendance averages via Eloquent's `withAvg('students', 'attendance_rate')` and calculating low-attendance classes in memory reduced total queries significantly. Additionally, wrapping view composer notification queries in Laravel 12's `once()` helper prevents duplicate database queries when multiple view partials are rendered during a single request.
**Action:** Always check view composers and collection loops for hidden N+1 database queries; use Eloquent's `withAvg()`/`withCount()` and request-scoped `once()` memoization helper.
