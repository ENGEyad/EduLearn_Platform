## 2026-05-18 - Deduplicating Assigned Class Sections in Teacher Student Calculations
**Learning:** In models with many-to-many or multi-assignment relations (like `TeacherClassSubject`), a model can be linked to the same parent entity (`ClassSection`) multiple times for different sub-entities (e.g. `Subject`). Iterating over assignments without deduplicating class sections by ID leads to over-counting (e.g., double or triple counting students) and redundant query execution if count aggregates are evaluated on each assignment.
**Action:** Deduplicate parent models by `id` (e.g., `->unique('id')`) prior to aggregating counts across related models, and prefer Eloquent count queries (`$cs->students()->count()`) or pre-calculated attributes over hydrating entire Eloquent model collections.
