## 2026-08-22 - Optimize low-attendance classes query in DashboardAnalyticsService
**Learning:** `DashboardAnalyticsService::buildOverview` executed an individual query per class section in a `.filter()` loop to compute average student attendance rates (`Student::where('class_section_id', $section->id)->avg('attendance_rate')`), causing $N+1$ database queries. Pre-calculating all section attendance averages with a single grouped query (`Student::where('school_id', $schoolId)->whereNotNull('class_section_id')->groupBy('class_section_id')->pluck(DB::raw('AVG(attendance_rate)'), 'class_section_id')`) eliminates the $N+1$ bottleneck and reduces query execution count from 22 down to 12.
**Action:** When computing aggregates across related entities (such as class sections), use grouped subqueries or `pluck` with raw aggregates instead of iterating over collections with database queries.
