## 2026-05-13 - Teacher Model Assigned Students and Subjects Optimization
**Learning:** In `Teacher::getTotalAssignedStudentsAttribute()`, iterating over `assignments` without deduplicating `classSection` caused duplicate counting when a teacher teaches multiple subjects in the same section, and accessing `$cs->students->count()` when `students_count` was not loaded hydrated every student model into memory. In `Teacher::getAssignedSubjectsAttribute()`, accessing `$as->subject->name` returned null because `Subject` uses `name_en` and `name_ar` with a `display_name` accessor.
**Action:** Always deduplicate parent entities (`unique(fn($cs) => $cs->id)`) before summing aggregate statistics, check `$cs->relationLoaded('students')` before resorting to `$cs->students()->count()` query execution, and use `$subject->display_name ?? $subject->name_en ?? $subject->name_ar` when extracting subject titles.
