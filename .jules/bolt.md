## 2025-05-18 - Deduplicating Class Sections and Using Aggregate Queries in Teacher Accessors
**Learning:** In Eloquent models, accessors that reduce over `hasMany` relationships without deduplication can overcount values when a model has multiple child records referencing the same related entity (e.g., a teacher teaching multiple subjects in the same class section). Additionally, calling `$cs->students->count()` on non-preloaded relationships hydated all model instances into memory, whereas `$cs->students()->count()` executes a lightweight SQL `COUNT(*)` query.
**Action:** Always deduplicate related collections using `unique('id')` before summing aggregate counts in accessors, and use `$relation()->count()` or `$relation_count` attributes rather than `$relation->count()`.
