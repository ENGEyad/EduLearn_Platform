## 2025-05-15 - [N+1 Query Bottleneck in ReportsController::list]
**Learning:** The `ReportsController::list` method iterates over distinct class sections and performs a separate query for every section to count students. This results in an N+1 query pattern where N is the number of class sections. For a school with 20 sections, this triggers 21+ queries just to load the basic list. Additionally, searching for students within these classes is currently done by cloning the student query in each loop iteration, further compounding the performance hit.
**Action:** Use `groupBy` and `selectRaw` with `count(*)` to fetch class sections and student counts in a single query. Use `whereExists` for efficient database-level filtering when searching by student name/ID across classes.
