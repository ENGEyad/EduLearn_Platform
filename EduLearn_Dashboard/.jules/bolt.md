## 2026-05-15 - [Resolving Dashboard N+1 Queries and Dual-Database testing connection leaks]
**Learning:** Eager-loading aggregates using Eloquent's `withAvg` is a powerful way to resolve N+1 query loops over collections. Reusing already fetched Eloquent collections for simple counts avoids redundant DB query roundtrips. When dealing with dual-database setups during SQLite feature testing, we must never commit temporary connection modifications to production migrations or models, but rather use temporary edits and restore them before the final PR submission to prevent production regressions.
**Action:** Always inspect loops over Eloquent collections for hidden DB queries like counts or averages. Use temporary local connection changes to verify feature tests on SQLite locally, and systemically use `git checkout/restore` to completely revert connection modifications prior to final review and submission.
