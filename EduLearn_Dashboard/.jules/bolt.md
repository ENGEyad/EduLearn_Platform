## 2025-05-15 - [Database Connection Overrides for Isolated SQLite Tests]
**Learning:** Hardcoded connections in Laravel models and migrations (like `app_mysql` and `mysql`) can cause test runs to fail with connection errors since those connections do not point to active SQLite databases during tests. Overriding `mysql` and `app_mysql` connections dynamically in `TestCase::createApplication()` to point to in-memory SQLite allows migrations to run flawlessly without making intrusive, non-standard, or risky architectural changes in migration or model files.
**Action:** When working on isolated feature tests requiring database migrations on custom connections, dynamically inject database overrides via `config()` inside `TestCase::createApplication()` instead of manually modifying global configurations or migrations.
